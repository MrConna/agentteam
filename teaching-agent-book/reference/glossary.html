通信机制（不共享上下文时）

机制适用场景AgentTeam 对应
工具调用参数结构化数据传递，类型确定—
共享文件系统产物较大或需持久化同一文件系统下读写
消息总线异步通信，发送方和接收方无需同时在线session_send (Mailbox)

选择原则

  • 累计上下文 > 窗口 50% → 不共享上下文
  • 信息零损耗是硬约束 → 共享上下文
  • 多数实际系统 → 阶段切换：先共享，到饱和点切换为不共享 + handoff
  • 多 Agent 开销约为单 Agent 的 3-15 倍 → 效果收益必须覆盖开销
