# AI Agent 学习资源

## Knowledge

- [Book: 《深入理解 AI Agent：设计原理与工程实践》— 李博杰](https://github.com/bojieli/ai-agent-book)
  全书开源，正文在 `book/` 目录 `chapter1.md` ~ `chapter10.md`，编译版 PDF 在 `book/深入理解-AI-Agent-李博杰-v1.1.pdf`。
  配套代码按章节组织在 `chapterN/` 下。**核心公式：Agent = LLM + 上下文 + 工具**。
  使用场景：所有 lesson 的知识来源。

- [Paper: "AI Agents That Matter" — 2025](https://arxiv.org/abs/2502.11561)
  Agent 评估的严肃讨论。Use for: 第 6 章 Agent 评估的补充阅读。

- [Paper: "The Second Half" — Shunyu Yao](https://srush.github.io/llm-agents/)
  LLM 作为 Agent 的范式转变讨论。Use for: 第 1 章的基础理解。

## Wisdom (Communities)
